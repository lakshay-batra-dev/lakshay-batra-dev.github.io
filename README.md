# Lakshay Batra — Portfolio

Personal portfolio website built with React, TypeScript, Tailwind CSS, and Vite.

## Tech Stack

- **React 18** + TypeScript
- **Tailwind CSS** + shadcn/ui
- **Vite** (build tool)
- **Space Grotesk** + **JetBrains Mono** (fonts)

## Local Development

```sh
npm install
npm run dev
```

## Deploy to GitHub Pages

```sh
npm run deploy
```
